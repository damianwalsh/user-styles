# user-styles

1. Install [Stylus for Chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) or [Stylus for Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/).
2. Open the .user.css file you want in this repo.
3. Click Raw. Stylus will open an installation page.
4. Click Install style, leaving automatic updates enabled.
